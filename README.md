# mini-Balanced-infantry

本项目是面向 RoboMaster 的小型轮腿平衡步兵验证项目，仓库收录了 2023、2025 两个版本的总装配资料及物料清单，用于结构设计、装配和后续功能验证。

## 当前进度

目前已完成以下基础功能验证：

- 平衡
- 起身

跳跃等进阶运动功能尚未进行测试，当前项目验证结论仅覆盖平衡与起身功能。

## 仓库内容

- `2023/`：2023 版本总装配资料
- `2025/`：2025 版本总装配资料
- `bom.xlsx`：项目物料清单

## 大文件说明

总装配压缩包使用 Git LFS 管理，克隆仓库前请安装并启用 Git LFS。
