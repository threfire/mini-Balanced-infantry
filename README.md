# mini-Balanced-infantry

本项目是面向业余爱好者的桌面级小型串联轮腿平衡步兵验证项目，仓库收录了 第一版2023、2025 两个版本，第二版2025版本的总装配资料及物料清单，用于结构设计、装配和后续功能验证。
完整拼装成本2500rmb+，重2.5kg，站姿离地高度20cm。
垂直投影前后长200mm，宽200mm，个人认为属于桌面级小腿。
## 当前进度

目前已完成以下基础功能验证：

- 平衡
- 起身

跳跃等进阶运动功能尚未进行测试，当前项目验证结论仅覆盖平衡与起身功能。
